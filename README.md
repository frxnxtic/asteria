# 🌟 АСТЕРИЯ

Волшебное 3D-приключение в открытом ночном мире планеты звёздных магов. Сделано с 💜 для одной единственной героини.

**Играть:** https://frxnxtic.github.io/asteria/

## Что внутри (M4 «Живой мир»)

- 🌧 **Дождь**: капли-линии, мягкий шум, зарницы; в дождь светлячки крупнее и ярче — её любимое из опросника
- 🍄 **Дождевые грибы**: светятся только в дождь, сбор → зелье росы
- 👩‍🍳🧙‍♂️ **Жители Гавани**: трактирщица Мила и звездочёт Борей (с телескопом) — реплики меняются по главам
- 👗 **Рундук нарядов** у костра: цвета плаща за блёстки («Закатная роза», «Изумруд тумана», «Золотой час», «Багрянец»), шлейф Блика — в цвет плаща
- ✨ **Танец светлячков**: живой рой раз в несколько минут — успей коснуться (+6 светлячков)
- Всё из M1–M3: главы 1–2, три загадки, босс, созвездие Лисы, блёстки, падающие звёзды, бои, зелья, музыка, сейвы

## Управление

iPad: джойстик слева, камера — свайп справа, кнопки ✦ атака / 💫 Блик / 🧪 зелье / ⬆️ прыжок / контекстное действие.
Компьютер: WASD + мышь, J — атака, B — Блик, Q — зелье, E — действие.

## Установка на iPad

Открой ссылку в Safari → «Поделиться» → «На экран “Домой”» — появится иконка, игра станет работать как приложение, офлайн.

## Разработка

```bash
python3 tools/serve.py 8765      # дев-сервер без кэша: http://localhost:8765
python3 tools/build.py           # сборка одним файлом: dist/asteria.html
python3 tools/gen_icons.py       # регенерация PWA-иконок
```

**Стек:** Three.js (WebGL2), vanilla JS (ES-модули, без сборщиков и зависимостей), Web Audio, PWA.
