# 🌟 АСТЕРИЯ

Волшебное 3D-приключение в открытом ночном мире планеты звёздных магов. Сделано с 💜 для одной единственной героини.

**Играть:** https://frxnxtic.github.io/asteria/

## Что внутри (M3 «Созвездие»)

- 🌲 **Сумеречный лес**: осенние деревья, тыквы с мордочками, грибы-фонарики, врата, каменное святилище
- 🧩 **Три загадки**: световые зеркала (доведи луч до обелиска), плита созвездия Лисы (соедини звёзды), грибы-колокольчики (повтори песню)
- ⚔️ **Босс Пожиратель Света**: 3 фазы — рывки с телеграфом, призыв миньонов, кольца-волны; свита гибнет вместе с хозяином
- 🦊 **Вау-момент**: после победы созвездие Лисы вспыхивает в ночном небе (и остаётся навсегда)
- 💎 **Блёстки**: 5 сундуков-тайников в лесу + алтарь святилища (6 💎 → +1 макс HP, до 7)
- 🌟 **Событие «Падающая звезда»**: раз в несколько минут звезда падает в случайное место — успей за 75 секунд
- 🧭 Компас к текущей цели, возрождение у святилища в бою с боссом
- Всё из M1–M2: бои, Блик-телепорт, глава 1, Дэн и Искра, зелья, день/ночь, музыка, сейвы

## Управление

iPad: джойстик слева, камера — свайп справа, кнопки ✦ атака / 💫 Блик / 🧪 зелье / ⬆️ прыжок / контекстное действие.
Компьютер: WASD + мышь, J — атака, B — Блик, Q — зелье, E — действие.

## Установка на iPad

Открой ссылку в Safari → «Поделиться» → «На экран “Домой”» — появится иконка, игра станет работать как приложение, офлайн.

## Разработка

```bash
python3 tools/serve.py 8765      # дев-сервер без кэша: http://localhost:8765
python3 tools/build.py           # сборка одним файлом: dist/asteria.html
python3 tools/gen_icons.py       # регенерация PWA-иконок
```

**Стек:** Three.js (WebGL2), vanilla JS (ES-модули, без сборщиков и зависимостей), Web Audio, PWA.
