# 🌟 АСТЕРИЯ

Волшебное 3D-приключение в открытом ночном мире планеты звёздных магов. Сделано с 💜 для одной единственной героини.

**Играть:** https://frxnxtic.github.io/asteria/

## Что внутри (M2 «Искра»)

- ⚔️ **Боевая система**: звёздные снаряды с автоприцелом (✦), Блик-телепорт с неуязвимостью (💫), HP-звёзды, зелья (🧪)
- 🌫️ **Мгла**: ползучие тени + элита, волна-нападение, трофеи-светлячки, смерть → возрождение у костра
- 📖 **Глава 1 «Пробуждение Гавани»**: квесты, диалоги с портретами, виджет цели, полный прогон от пробуждения до финала
- 🧑 **Дэн** — странник-хранитель с фонарём у костра; 🐾 **Искра** — звёздный лисёнок-спутник
- 🌙 **Лунные травы** (светятся, собираются прикосновением), **котелок**: зелье ночного зрения по сюжету + рецепт «Зелье росы» (2 травы → лечение)
- 🌃 **Ночная Гавань** — тайный город магов: площадь, домики с тёплыми окнами, мост через ручей, кристаллы, плавучие островки
- 🦸‍♀️ **Юляся** — героиня с плащом-небом и посохом-звездой
- 🕹️ Управление как в Genshin: виртуальный джойстик + свайп камеры (на компьютере — WASD, J — атака, B — Блик, Q — зелье, E — действие)
- 🌙 Полный цикл дня и ночи, звёзды, луна, туман
- 🏮 9 фонарей, которые можно зажечь
- ✨ Светлячки — валюта (капают и с Мглы)
- 🎻 Генеративная оркестровая музыка + боевые звуки (Web Audio, без единого аудиофайла)
- 💾 Автосохранения: позиция, прогресс главы, травы, зелья

## Установка на iPad

Открой ссылку в Safari → «Поделиться» → «На экран “Домой”» — появится иконка, игра станет работать как приложение, офлайн.

## Разработка

```bash
python3 tools/serve.py 8765      # дев-сервер без кэша: http://localhost:8765
python3 tools/build.py           # сборка одним файлом: dist/asteria.html
python3 tools/gen_icons.py       # регенерация PWA-иконок
```

**Стек:** Three.js (WebGL2), vanilla JS (ES-модули, без сборщиков и зависимостей), Web Audio, PWA.
