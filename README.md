# 🌟 АСТЕРИЯ

Волшебное 3D-приключение в открытом ночном мире планеты звёздных магов. Сделано с 💜 для одной единственной героини.

**Играть:** https://frxnxtic.github.io/asteria/

## Что внутри — полная игра

**Три главы и три судьбы неба:**

- 📖 **Глава 1 «Пробуждение Гавани»** — знакомство с Дэном, лунные травы, первое зелье, волна Мглы, лисёнок Искра
- 🌲 **Глава 2 «Сумеречный лес»** — три загадки (зеркала, плита созвездия, колокольчики), босс Пожиратель Света, созвездие Лисы вспыхивает в небе
- 🌌 **Глава 3 «Сердце Тиши»** — мост света, финальный бой с Тишью (Дэн сражается рядом), **выбор из трёх концовок**: «Развеять Тишь» ✨, «Понять и исцелить» 💗 (открывается за 3+ тайника), «Отдать свой свет» 🌟 — и титры с именем героини

**Живой мир:**

- 🌧 Дождь с зарницами; в дождь светлячки ярче, появляются дождевые грибы (→ зелья)
- 👩‍🍳🧙‍♂️ Жители: трактирщица Мила и звездочёт Борей — реплики меняются по главам
- 👗 Наряды за блёстки (4 цвета плаща, шлейф Блика в цвет)
- 🌟 Падающие звёзды и танец светлячков — живые события
- ⚔️ Боевая система: снаряды с автоприцелом, Блик-телепорт, HP до 7, зелья, алтарь улучшений
- 🦮 Искра бежит следом, компас ведёт к цели, всё автосохраняется
- 🔁 **NG+**: после финала у Дэна — прожить историю заново, сохранив коллекции и наряды

## Управление

iPad: джойстик слева, камера — свайп справа, кнопки ✦ атака / 💫 Блик / 🧪 зелье / ⬆️ прыжок / контекстное действие.
Компьютер: WASD + мышь, J — атака, B — Блик, Q — зелье, E — действие.

## Установка на iPad

Открой ссылку в Safari → «Поделиться» → «На экран “Домой”» — появится иконка, игра станет работать как приложение, офлайн.

## Разработка

```bash
python3 tools/serve.py 8765      # дев-сервер без кэша: http://localhost:8765
python3 tools/build.py           # сборка одним файлом: dist/asteria.html
python3 tools/gen_icons.py       # регенерация PWA-иконок
```

**Стек:** Three.js (WebGL2), vanilla JS (ES-модули, без сборщиков и зависимостей), Web Audio, PWA.
