# 🌟 АСТЕРИЯ

Волшебное 3D-приключение в открытом ночном мире планеты звёздных магов. Сделано с 💜 для одной единственной героини.

**Играть:** https://frxnxtic.github.io/asteria/

## Что внутри (M1 «Первый свет»)

- 🌃 **Ночная Гавань** — тайный город магов: площадь, домики с тёплыми окнами, мост через ручей, кристаллы, плавучие островки
- 🦸‍♀️ **Юляся** — героиня с плащом-небом и посохом-звездой
- 🕹️ Управление как в Genshin: виртуальный джойстик + свайп камеры (на компьютере — WASD + мышь)
- 🌙 Полный цикл дня и ночи, звёзды, луна, туман
- 🏮 9 фонарей, которые можно зажечь
- ✨ Светлячки — первая коллекционная валюта
- 🎻 Генеративная оркестровая музыка (Web Audio, без единого аудиофайла)
- 💾 Автосохранения в localStorage

## Установка на iPad

Открой ссылку в Safari → «Поделиться» → «На экран “Домой”» — появится иконка, игра станет работать как приложение, офлайн.

## Разработка

```bash
python3 -m http.server 8765   # дев-версия: http://localhost:8765
python3 tools/build.py        # сборка одним файлом: dist/asteria.html
python3 tools/gen_icons.py    # регенерация PWA-иконок
```

**Стек:** Three.js (WebGL2), vanilla JS (ES-модули, без сборщиков и зависимостей), Web Audio, PWA.
